2. Perform final consolidated review of all School Management SaaS P00–P67 implementation, documentation, migrations, open gaps and test evidence.
3. Run all available static verifiers and syntax checks; clearly separate these from unrun runtime acceptance.

5. Consolidate the open-gap register without dropping history; only close items with verifiable implementation and execution evidence.
