# P16 Entry Criteria

1. Establish pnpm lockfile and install all dependencies reproducibly.
2. Run Prisma validation/generation and migrations on clean and upgrade databases.
3. Test teacher assignment isolation across organization, school, academic year, grade, section and effective dates.
4. Add API integration tests for teacher list/roster/create/open/mark/submit and admin lock.
5. Implement production mobile authentication and secure token storage/refresh.
6. Add offline attendance queue with explicit duplicate/conflict reconciliation.
7. Add teacher timetable/day view and class/subject navigation.
8. Implement guardian attendance read access and notifications with consent controls.
9. Run Expo typecheck/build and device E2E tests.
10. Carry all unresolved gaps forward and close only with evidence.
