# P20 Entry Criteria — Academic Calendar & Timetable Exceptions

1. Design date-specific timetable overrides, cancellations and substitute-teacher assignments.
2. Integrate school holidays and calendar events with teacher timetable visibility.
3. Define room inventory and canonical room identifiers.
4. Add CSV import/export with strict parsing, preview and downloadable error report.
5. Add concurrency-safe teacher/room conflict prevention at persistence level.
6. Add School Admin timetable editor and teacher week navigation.
7. Add PostgreSQL/RLS/API integration tests and device/browser E2E coverage.
8. Run Prisma validation, generated-client typecheck, migrations and full CI before declaring runtime acceptance.
