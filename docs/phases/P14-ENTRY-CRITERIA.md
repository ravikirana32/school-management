# P14 Entry Criteria

1. Validate Prisma and apply P12/P13 migrations on clean and upgrade databases.
2. Run the P13 integration plan using PostgreSQL and the actual application DB role.
3. Verify entitlement checks and school role grants endpoint-by-endpoint.
4. Connect School Admin and Teacher attendance UI to persisted APIs.
5. Integrate attendance policy, timetable periods, calendar, timezone and holidays.
6. Implement guardian read-only attendance with explicit access controls.
7. Add notification outbox, retry, consent and delivery status.
8. Complete concurrency tests and observability.
9. Carry unresolved P00–P13 gaps forward; close only with evidence.
