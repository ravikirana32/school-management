# P12 entry criteria — Student attendance foundation

- Daily attendance sessions and student attendance records with school calendar/timezone rules.
- Teacher authorization limited to assigned classes/sections and permitted attendance actions.
- Late, absent, half-day, excused and leave states with correction approval/audit.
- Duplicate prevention and concurrency-safe class attendance submission.
- Parent-facing attendance visibility only after verified guardian linking and consent.
- Notifications and reporting foundations with privacy-safe payloads.
- Full API, RLS, authorization, browser and concurrency tests.
- Carry forward every unresolved P00–P11 gap; close only with implementation and evidence.
