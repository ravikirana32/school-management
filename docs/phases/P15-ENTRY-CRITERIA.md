# P15 Entry Criteria

1. Install pinned workspace dependencies and generate the pnpm lockfile.
2. Run Prisma validate/generate and apply P12–P14 migrations to clean and upgrade databases.
3. Run API integration and PostgreSQL RLS tests for roster and attendance workflows.
4. Build the School Admin app and add browser E2E for create/open/mark/submit/lock.
5. Add lookup pickers for academic years and grades, pagination for large rosters, and clear duplicate/session conflict handling.
6. Implement teacher mobile attendance with assignment-scoped roster and marks.
7. Add guardian read-only attendance and notifications with privacy/consent controls.
8. Integrate calendar, attendance policy, timetable periods and timezone behavior.
9. Close gaps only with implementation and verification evidence.
