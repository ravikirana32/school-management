# P162 — Operational Alert Delivery

## Delivered
- Durable `OperationsAlertOutbox` with unique dedupe keys and due-work index.
- Configurable worker failure threshold and stale-heartbeat threshold.
- Critical degraded-worker alert after configured consecutive failures.
- Recovery notification when a degraded worker returns healthy.
- Authenticated webhook delivery with provider idempotency key.
- Capped exponential retry and durable error metadata.

## Configuration
- `OPERATIONS_ALERT_WEBHOOK_URL`
- `OPERATIONS_ALERT_WEBHOOK_TOKEN` (or `_FILE`)
- `DOCUMENT_WORKER_FAILURE_ALERT_THRESHOLD` (default 3)
- `DOCUMENT_WORKER_STALE_AFTER_SECONDS` (default 120)

Webhook delivery is disabled until URL and token are configured. Apply migration `20261118250000_p162_operations_alert_delivery` before deploying.

## Outstanding
